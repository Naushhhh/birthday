HEARTCRAFT BIRTHDAY CARD

Quick start:
1. Open index.html in Chrome/Edge to preview.
2. Enter code 0518 in the card preview.
3. Use “Add your photos” to select up to 5 pictures.
4. For QR sharing, deploy this folder to a static host (for example Netlify or GitHub Pages), then paste the hosted URL into “Shareable Website URL” and click “Create QR preview”.

Important:
- This is a lightweight, standalone HTML project; no npm install required.
- Photo uploads and unlock are client-side demo behavior. This passcode is not secure authentication; anyone with source code can inspect it.
- QR preview depends on an online QR image service.
